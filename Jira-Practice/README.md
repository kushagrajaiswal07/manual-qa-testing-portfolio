# Jira QA Practice Project

## Overview
This project demonstrates my beginner-level hands-on practice with Jira issue tracking, using observations from my manual QA testing assessment of the InstaDost website.

## What I Practiced
- Creating and documenting bug tickets
- Writing steps to reproduce defects
- Defining expected and actual results
- Assigning provisional priorities
- Organizing issues with labels and workflow statuses

## Sample Defects
- Product images displaying incorrectly
- Shipping fee not recalculated below the free-shipping threshold
- Order total not including tax
- Unexpected logout and cart state reset
- Address and postal-code validation issues

Screenshots of my Jira practice board and a sample issue are included in this folder.

## Note
This is a personal learning project based on observed testing behavior. It is not professional Jira experience or an official project managed by InstaDost.
