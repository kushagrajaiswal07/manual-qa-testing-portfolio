# Manual QA Testing — Test Scenarios

## Project Overview
**Application:** InstaDost E-commerce Website  
**Testing Type:** Manual Testing  
**Project:** QA Tester Intern Assessment

## Test Scenarios

| Scenario ID | Test Scenario | Priority |
|---|---|---|
| TS-001 | Verify that users can search for products using valid keywords. | High |
| TS-002 | Verify search behavior when users enter invalid or nonexistent product names. | Medium |
| TS-003 | Verify that product images load correctly on the website. | High |
| TS-004 | Verify that broken or unavailable product images are handled appropriately. | High |
| TS-005 | Verify that product names, prices, and details are displayed correctly. | High |
| TS-006 | Verify that users can add products to the shopping cart. | High |
| TS-007 | Verify that users can remove products from the shopping cart. | High |
| TS-008 | Verify that cart quantities update correctly when users repeatedly click Add to Cart. | High |
| TS-009 | Verify that the cart displays the correct products and quantities. | High |
| TS-010 | Verify that wishlist functionality works as expected. | Medium |
| TS-011 | Verify that users can add products to and remove products from the wishlist. | Medium |
| TS-012 | Verify that shipping charges are calculated correctly. | High |
| TS-013 | Verify that the order total reflects product prices, quantities, and applicable charges. | High |
| TS-014 | Verify that the website handles empty search inputs appropriately. | Medium |
| TS-015 | Verify that loading indicators and error states behave appropriately when content fails to load. | Medium |
| TS-016 | Verify that cart and wishlist contents behave consistently during website navigation. | Medium |
| TS-017 | Verify that repeated user interactions do not produce unintended results. | High |
| TS-018 | Verify that the website provides appropriate feedback when an action fails. | Medium |

## Testing Approach

- Reviewed key e-commerce user flows.
- Performed manual functional and exploratory testing.
- Compared actual behavior with expected behavior where applicable.
- Identified unexpected behavior and documented potential defects.
- Considered positive, negative, and boundary scenarios.

## Scope and Limitations

These scenarios describe the planned testing coverage for the assessment. Actual execution status and pass/fail results should be verified against the corresponding test cases and execution records.
